# 4채널 LM324 비교기 회로: PSpice 체험판 노드 제한 회피

LM324 모델 1개(op-amp 한 섹션)는 내부 노드를 15개 씁니다. 4개를 다 넣으면 외부 노드까지 합쳐 75개를 넘어서 체험판에서는 돌아가지 않습니다.

## 방법 1: 섹션별로 나눠서 시뮬레이션 (LM324 실제 모델 그대로)

| 파일 | 비교기 | -입력 기준전압 | VIN=6V일 때 결과 |
|---|---|---|---|
| `stage1_U1A.cir` | U1A → R5, D1 | 9.6 V | OFF (출력 ≈ 0 V) |
| `stage2_U1B.cir` | U1B → R6, D2 | 7.2 V | OFF |
| `stage3_U1C.cir` | U1C → R7, D3 | 4.8 V | ON (출력 ≈ 10.5 V) |
| `stage4_U1D.cir` | U1D → R8, D4 | 2.4 V | ON |

각 파일에는 전원, 스위치, 분배저항 5개(R9, R1~R4), 커패시터 4개가 모두 들어 있어서 기준전압과 부하 조건이 원래 회로와 같습니다. 바뀌는 건 op-amp 한 섹션과 그 출력의 R, D뿐입니다. 노드는 파일당 약 26개입니다.

## 방법 2: 한 번에 전체 시뮬레이션 (`full_simple_comparator.cir`)

LM324를 간단한 행동모델 비교기(ETABLE, 출력 0 V / 10.5 V)로 바꾼 버전입니다. 노드가 약 23개라 4채널을 한 번에 볼 수 있습니다.

## 실행 방법

PSpice(AD Lite)에서 **File → Open → `.cir` 파일 선택 → Run** 을 누르면 됩니다. Capture 없이 바로 돌아갑니다.

## Capture 회로도에서 직접 나누려면

1. 프로젝트를 4개로 복사합니다(또는 Schematic 페이지 4개를 만들고 시뮬레이션마다 하나만 쓰도록 합니다).
2. 각 회로도에서 op-amp는 **한 섹션만 남기고**(예: U1A만) 나머지 섹션(U1B, U1C, U1D)과 그 출력의 R, D를 삭제합니다.
   배치하지 않은 섹션은 넷리스트에 들어가지 않으므로 노드가 15개씩 줄어듭니다.
3. VCC/VIN 전원, 스위치 U2, 분배저항 R9·R1~R4, C1~C4는 **지우지 마세요**. 지우면 기준전압이 달라집니다.
