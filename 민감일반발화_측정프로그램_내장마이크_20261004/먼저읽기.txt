일반·민감 발화 측정 프로그램 — Windows 64비트 본체용

1. ZIP을 본체로 옮기고 압축을 모두 풉니다.
2. START.cmd를 실행합니다. Python 설치는 필요 없습니다.
3. 입력 장치 목록에서 본체에 실제 연결한 마이크 이름을 선택합니다.
   Microsoft 사운드 매퍼·스테레오 믹스 대신 실제 마이크 입력을 선택하세요.
   CM-5050pro의 경우 본체의 마이크 단자에 음성선, USB에 전원선을 연결합니다.
4. 녹음 시작을 누르고 초기 1.5초는 조용히 기다립니다.
5. 일반 또는 민감 형식 문장을 말한 뒤 잠시 쉽니다.
6. 특징과 판정이 나오면 실제 정답 '일반 / 민감 / 모름' 버튼을 누릅니다.
   정답은 프로그램 출력이 맞는지 여부가 아니라 방금 말한 문장의 실제 유형입니다.
   정답을 누르면 다음 발화를 받습니다. 실제 개인정보 대신 실험용 가상 자료를 사용하세요.
7. 중지를 누른 뒤 '저장 폴더 열기'를 누릅니다.
   program/records의 새 speech_compare_날짜_시간.csv를 보내주세요.

계획된 20문장 대본을 순서대로 읽고 싶다면 CONTROLLED_20.cmd를 사용합니다.
START와 CONTROLLED_20을 동시에 녹음시키지 마세요.

화면에 표시되는 것
- 음향 피크율(자동 음절 수로 확정할 수 없음)
- Jitter, Shimmer, F0, 침묵 길이
- 개인 기준선 판정, 기존 비교 모델 판정, 사용자가 입력한 정답
- 측정이 불안정하면 판정 보류

기존 화면과 기존 45개 기준선을 포함했습니다. 새 45개 수집부터 시작할 필요는 없습니다.
다만 이 기준선은 과거 내장 마이크에서 만든 참고값입니다. 본체·외장 마이크의
새 특징과 동일 조건의 기준선이 아니므로 현재 분류 결과를 정확도 검증 완료로 해석하지 마세요.
기준선 초기화를 누르면 다시 수집 단계가 됩니다. 원래 참고값 사본은
program/reference_baseline_original.json에 별도 보존했습니다.

구간 보정과 문맥별 측정 검사, 보류 시 기준선 반영 차단이 적용돼 있습니다.
실험용 보조 Shimmer나 v2 피크 계수기로 분류값을 대체하지 않았습니다.
분류 임계값과 기존 모델을 새 녹음에 맞춰 변경하지 않았습니다.

이 프로그램은 수치와 정답을 로컬 CSV로 기록합니다. 원본 음성은 저장하지 않습니다.
음성을 외부 서비스에 전송하거나 STT를 사용하지 않습니다.
녹음 저장이 필요한 지속모음 검사는 이전 마이크비교 패키지의 별도 기능입니다.

이 PC에서 패키지 실행·특징 추출·GUI 결과 및 정답 CSV 저장을 확인했습니다.
다른 본체에서의 마이크 연결과 실시간 녹음은 해당 본체에서 확인해야 합니다.
